# Code reconciliation report

## Canonical calculation path

1. `revision/recompute_entity_split_metrics.py` loads the released Davis inputs,
   embedding cache, and each released checkpoint.
2. It builds each model from `checkpoint['config']` and evaluates with
   `torch.inference_mode()` in full precision.
3. It writes separate validation/test prediction CSVs. The F1 threshold comes
   only from validation predictions and is frozen for the corresponding test
   predictions.
4. `revision/promote_canonical_entity_metrics.py` refuses non-canonical input
   artifacts, copies canonical test CSVs into `BioInteract/results/figure_data/`,
   and writes the public summary JSON and bootstrap intervals.
5. `BioInteract/src/analysis/generate_figures.py` reads that canonical summary
   for the original entity-split panel; it does not silently re-infer or read a
   legacy metric artifact.

## Provenance anchors

- Canonical artifact: `revision/analysis/original_entity_split_metrics.json`
- Provenance narrative: `revision/analysis/reproducibility_manifest.md`
- Canonical validation/test predictions:
  `revision/analysis/*_{validation,test}_predictions.csv`
- Public promoted predictions:
  `BioInteract/results/figure_data/predictions_*.csv`
- Strict stress-test artifacts:
  `revision/analysis/strict_split_metrics.json`
- Exact audited environment: `BioInteract/requirements-audit.txt`

The artifact records SHA-256 hashes for raw Davis tables, the cached ESM
embeddings, model configurations, and all three checkpoints. The release
reconstruction uses Python 3.10.14, PyTorch 2.4.0+cu121, and full precision on
the CUDA device recorded in the artifact.

## Retired historical claims

Earlier entity-split score files matched the recorded identifiers and labels but
not the scores generated by the released current checkpoints and inputs. They
are not used in the revised manuscript, public result summary, release figures,
or DOI archive. Likewise, numerical ablation conclusions are omitted because
the necessary ablated-model checkpoint/prediction pairs are not archived.
